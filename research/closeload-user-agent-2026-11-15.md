# CloseLoad erişim karşılaştırması — 15 Kasım 2026

Kod kopyalanmadı. Sağlayıcı JSON-LD `contentUrl` fallback'i de kullanıyor; eski veya tuzak olabileceğinden bunu uygulamadık.

FM Rapid kısa UA 1 HTTP 403, 77 ağ hatası; Chrome 1 HTTP 403, 1 HTTP 451, 76 ağ hatası. Bu tek başarılı HTML'e karşılık gelen akışın cihazda oynatılması doğrulanmadı; S08E01 de doğrulanmadı.
